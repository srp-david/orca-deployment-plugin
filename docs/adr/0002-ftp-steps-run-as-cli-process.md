# 운영 FTP 단계는 워커가 CLI 프로세스를 따로 띄워 실행한다

Orca 플러그인 워커는 요청 하나에 최대 120초를 기다리고, 할 일이 없으면 5분 뒤 정리되며, dev 폴더가 바뀌면 다시 시작된다(Orca 1.4.250 기준). 업로드를 워커 안에서 돌리다가 중간에 끊기면 부분 업로드가 된다. 그래서 plan·백업·업로드·대조·되돌리기는 워커가 같은 엔진의 CLI를 떨어진 프로세스로 띄워 실행한다. 진행 상황은 run 폴더의 상태 파일로 주고받는다. 준비 확인, run 목록, 대상 설정처럼 짧은 일은 워커가 엔진을 직접 import해서 처리한다. 로직은 한 벌이고(ADR 0001), 실행만 프로세스를 나눈다.

접속 확인(로그인해서 운영 루트의 목록을 한 번 받아 보기)은 운영 FTP 에 접속하지만 워커가 직접 한다. 읽기 한 번이고 FTP 응답을 20초까지만 기다려서, 워커가 다시 시작돼 끊겨도 잃는 것이 없고 다시 누르면 된다.
