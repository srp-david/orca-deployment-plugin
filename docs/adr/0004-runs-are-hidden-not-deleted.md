# run 기록은 지우지 않고 화면에서만 숨긴다

run 기록 탭이 쌓여서 정리 기능이 필요했다. 그런데 업로드한 run에는 되돌리기용 백업이 있고, 되돌리기는 "같은 운영 파일을 건드린 나중 run이 있으면 막는다"는 판정을 run 기록으로 한다. 나중 run을 지우면 이 판정이 그 run을 못 보고, 앞 run을 되돌리다 더 새 반영을 덮어쓸 수 있다. 그래서 **목록 비우기**는 run 폴더에 `hidden` 표시만 남기고 화면에서 뺀다. 안전 검사와 PR 목록의 "반영됨" 표시는 숨긴 run도 본다. 부분 업로드 run은 되돌려야 하는 상태라 숨기지 않는다.

## Considered Options

- **올린 적 없는 run만 지우기**(plan됨·백업됨·막힘): 안전 검사에는 영향이 없지만, 지운 것은 되살릴 수 없다.
- **휴지통 폴더로 옮기기**: 되살릴 수 있지만, run 위치 색인과 run 찾기가 휴지통도 알아야 해서 복잡해진다.

## Consequences

- 디스크 공간은 줄지 않는다. run 폴더를 실제로 지우려면 사람이 직접 지운다(업로드한 run 은 지우지 않는다).
- **숨긴 run 보기**와 **모두 다시 보이기**로 언제든 되돌릴 수 있다.
